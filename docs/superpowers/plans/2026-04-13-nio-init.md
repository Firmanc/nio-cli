# nio init - Shell Integration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the `nio init` command to provide seamless shell integration via a `cd` wrapper and auto-completions for Bash, Zsh, and Fish.

**Architecture:** A new top-level `init` command will be added to `nio`. It will detect the user's shell (or accept an argument) and output a shell script containing a wrapper function and auto-completion logic generated by `clap_complete`.

**Tech Stack:** Rust, `clap` (v4), `clap_complete`

// src/init/mod.rs
use crate::cli::Shell;
use std::env;

pub fn detect_shell() -> Shell {
    let shell_path = env::var("SHELL").unwrap_or_default();
    if shell_path.ends_with("/zsh") {
        Shell::Zsh
    } else if shell_path.ends_with("/fish") {
        Shell::Fish
    } else {
        // Default to Bash for unknown or common paths (/bin/bash, /usr/bin/bash, etc.)
        Shell::Bash
    }
}

```rust
// src/init/mod.rs
use crate::cli::{Cli, Shell};
use clap::CommandFactory;
use clap_complete::{generate, shells};
use std::io;

pub fn handle_init(shell_arg: Option<Shell>) -> anyhow::Result<()> {
    let shell = shell_arg.unwrap_or_else(detect_shell);
    
    let wrapper = match shell {
        Shell::Bash | Shell::Zsh => format!(
            r#"nio() {{
    if [[ "$1" == "gtree" && "$2" == "switch" ]]; then
        local target=$(command nio gtree switch "${{@:3}}")
        if [[ -n "$target" ]]; then
            cd "$target"
        fi
    else
        command nio "$@"
    fi
}}
"#
        ),
        Shell::Fish => format!(
            r#"function nio
    if test "$argv[1]" = "gtree"; and test "$argv[2]" = "switch"
        set -l target (command nio gtree switch $argv[3..-1])
        if test -n "$target"
            cd "$target"
        end
    else
        command nio $argv
    end
end
"#
        ),
    };

    println!("{}", wrapper);

    // Generate completions
    let mut cmd = Cli::command();
    let bin_name = "nio";
    
    match shell {
        Shell::Bash => generate(shells::Bash, &mut cmd, bin_name, &mut io::stdout()),
        Shell::Zsh => generate(shells::Zsh, &mut cmd, bin_name, &mut io::stdout()),
        Shell::Fish => generate(shells::Fish, &mut cmd, bin_name, &mut io::stdout()),
    }

    Ok(())
}
```
